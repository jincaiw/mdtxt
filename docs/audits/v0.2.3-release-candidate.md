# v0.2.3 GA Release Evidence

Status: **published as an unsigned public GA release.**

## Released scope

v0.2.3 fixes recovered-tab activation on Windows by using the standard click
path for mouse and assistive-technology activation. The installed-package gate
restores two drafts after a forced process termination, locates the first tab
through Windows UI Automation, activates it through native input, refocuses the
editor and verifies both recovered bodies. The release also removes a duplicate
product label from the empty title bar and makes the welcome screen display the
current package version instead of the stale `0.1.0` literal.

Markdown files, export formats, application identity and updater policy are
unchanged.

## Assets and trust boundary

The public Release contains 11 assets: Apple Silicon DMG and app archive,
Windows x64 MSI, NSIS and portable packages, Ubuntu x64 DEB and AppImage,
`SHA256SUMS`, SPDX SBOM, portable checksum sidecar and third-party license
inventory. All seven package hashes in `SHA256SUMS` matched the corresponding
GitHub Release digests; the downloaded DMG also passed its local SHA-256 check.

The macOS app passes `codesign --verify --deep --strict` with identifier
`app.mdtxt.desktop`, but its signature is ad-hoc, has no Team ID and is not
notarized; Gatekeeper rejection is expected. Windows packages are not
Authenticode-signed. v0.2.3 is a GA product release, not a claim of platform
trust signing, and automatic updates remain disabled.
