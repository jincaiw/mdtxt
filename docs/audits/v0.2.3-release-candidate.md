# v0.2.3 Release-Candidate Decision

Status: **candidate for an unsigned public GA release.**

## Scope

v0.2.3 retains the v0.2.2 candidate and corrects the Windows packaged-app
recovery evidence to use `Alt+Left`. Windows WebView2 reserves the
`Ctrl+1` and `Ctrl+Shift+Tab` tab chords before the renderer receives them;
`Alt+Left` is the existing documented tab-cycle command and is forwarded to
the application. Markdown, exports, application identity and updater policy
are unchanged.

## Candidate gates

| Area | Required evidence before tagging |
| --- | --- |
| Keyboard reachability | Unit coverage and Windows production recovery prove restored unsaved drafts can cycle through the documented `Alt+Left` shortcut. |
| Platforms | Three-platform CI plus Windows/Linux native smoke are green for the candidate SHA. |
| Packages | macOS DMG verifies with ad-hoc deep signing; Windows x64 and Ubuntu x64 assets are downloaded and checked against SHA256SUMS. |
| Publication | Exactly one v0.2.3 draft Release has all expected assets, SPDX SBOM and license inventory before it is made public as GA. |

## Publication boundary

v0.2.3 is a GA release by product-owner direction, but it remains unsigned:
macOS is ad-hoc signed and not notarized, Windows Authenticode is NotSigned,
and updater JSON remains absent. The v0.2.0 tag and v0.2.1/v0.2.2 draft
releases remain immutable audit records; neither substitutes for v0.2.3
evidence.
