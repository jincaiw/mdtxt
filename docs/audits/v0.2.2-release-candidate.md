# v0.2.2 Release-Candidate Decision

Status: **candidate for an unsigned public GA release.**

## Scope

v0.2.2 carries forward the v0.2.1 product candidate and repairs the Windows
installed-package recovery evidence path. The recovery test now uses the
documented `Ctrl+Shift+Tab` cycle instead of a synthetic `Ctrl+1` chord that
WebView2 may retain at the host-accelerator layer. The app's command model,
Markdown format, exports, identity and updater policy are unchanged.

## Candidate gates

| Area | Required evidence before tagging |
| --- | --- |
| Keyboard reachability | Unit coverage and Windows production recovery prove restored unsaved drafts can cycle through the documented tab shortcut. |
| Platforms | Three-platform CI plus Windows/Linux native smoke are green for the candidate SHA. |
| Packages | macOS DMG verifies with ad-hoc deep signing; Windows x64 and Ubuntu x64 assets are downloaded and checked against SHA256SUMS. |
| Publication | Exactly one v0.2.2 draft Release has all expected assets, SPDX SBOM and license inventory before it is made public as GA. |

## Publication boundary

v0.2.2 is a GA release by product-owner direction, but it remains unsigned:
macOS is ad-hoc signed and not notarized, Windows Authenticode is NotSigned,
and updater JSON remains absent. The v0.2.0 tag and v0.2.1 draft remain
immutable audit records; neither substitutes for v0.2.2 evidence.
