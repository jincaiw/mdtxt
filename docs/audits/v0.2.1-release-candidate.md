# v0.2.1 Release-Candidate Decision

Status: **candidate for an unsigned public GA release.**

## Scope

v0.2.1 carries forward the v0.2.0 command, Live Beta and native-window work,
and fixes tab keyboard reachability for recovered unsaved drafts. Tab commands
now act on the session list rather than being incorrectly gated on a file path.
Markdown files, export formats, application identity and updater policy remain
unchanged.

## Candidate gates

| Area | Required evidence before tagging |
| --- | --- |
| Keyboard reachability | Unit coverage proves recovered unsaved tabs accept direct tab shortcuts; Windows production recovery verifies Restore all, both drafts and denied-share UX. |
| Platforms | Three-platform CI plus Windows/Linux native smoke are green for the candidate SHA. |
| Packages | macOS DMG verifies with ad-hoc deep signing; Windows x64 and Ubuntu x64 assets are downloaded and checked against SHA256SUMS. |
| Publication | Exactly one v0.2.1 draft Release has all expected assets, SPDX SBOM and license inventory before it is made public as GA. |

## Publication boundary

v0.2.1 is a GA release by product-owner direction, but it remains unsigned:
macOS is ad-hoc signed and not notarized, Windows Authenticode is NotSigned,
and updater JSON remains absent. The v0.2.0 tag and its unpublicized draft
remain immutable audit records; they are not a substitute for v0.2.1 evidence.
