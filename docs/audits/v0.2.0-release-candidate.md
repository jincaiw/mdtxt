# v0.2.0 Release-Candidate Decision

Status: **candidate for a public unsigned prerelease; not a GA declaration.**

## Scope

v0.2.0 delivers the shared command model, native menus and shortcuts,
source-preserving Typora-style Live Beta presentation, and native desktop window
chrome. It does not change Markdown files, export formats, application identity,
or updater policy.

## Candidate gates

| Area | Required evidence before tagging |
| --- | --- |
| Commands and localization | Full frontend tests, shortcut-conflict checks, i18n and user-copy gates pass; menus, palette and shortcuts dispatch one action. |
| Live Beta | Exact document/selection/undo round trips, malformed Markdown and Chinese IME fallbacks pass; Source remains default. |
| Window chrome | macOS Overlay traffic lights and title sync pass locally; Windows/Linux native smoke verifies system title bars and no simulated controls. |
| Packages | macOS release app/DMG verifies with ad-hoc deep signing; CI produces Windows x64 and Ubuntu x64 packages. |
| Release integrity | One draft prerelease, all expected assets, downloaded `SHA256SUMS`, SPDX SBOM and license inventory agree. |

## Publication boundary

The release must remain `prerelease=true`, ship no updater JSON, and make no
claim of Developer ID signing, notarization, or Windows Authenticode signing.
Final run IDs, asset digests, release URL and public timestamp are recorded only
after the candidate tag and release verification complete.
